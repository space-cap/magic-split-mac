# 🍎 프로젝트명: Magic Split Mac (Elixir Edition)

### 1. 기술 스택 (Tech Stack)
*   **언어**: Elixir (강력한 동시성 및 안정성)
*   **프레임워크**: Phoenix + LiveView (실시간 주가 UI를 자바스크립트 없이 구현)
*   **API**: 키움증권 REST API (맥/윈도우 호환 가능)
*   **데이터베이스**: SQLite (로컬 설치가 필요 없는 가벼운 DB)
*   **데스크톱 패키징**: Elixir Desktop (나중에 `.app` 파일로 변환할 때 사용)

### 2. 개발 환경
*   **OS**: 윈도우 10 (개발 및 테스트용)
*   **최종 타겟**: macOS (사용자 배포용)

### 3. 개발 로드맵 (3단계 전략)

#### **1단계: 핵심 기능 개발 (Web-based)**
*   엘릭서 프로젝트 생성 (SQLite 옵션 사용)
*   키움 REST API 연동 (OAuth2 인증 및 시세 조회)
*   그리드 매매(세븐스플릿) 로직 구현
*   Phoenix LiveView로 실시간 계좌 대시보드 제작

#### **2단계: 브라우저 활용 및 테스트**
*   로컬 서버(`localhost:4000`) 환경에서 실제 매매 테스트
*   그리드 매매 알고리즘의 안정성 검증 (에러 발생 시 자동 재시작 확인)

#### **3단계: 맥용 앱 패키징 (Desktop App)**
*   `elixir-desktop` 라이브러리 추가
*   더블 클릭 한 번으로 실행되는 `.app` 파일 제작
*   맥 상단 메뉴바(Tray 아이콘) 기능 추가

### 🚀 프로젝트 시작하기 (첫 번째 명령어)

윈도우 터미널(또는 VS Code 터미널)에서 아래 명령어를 입력하여 프로젝트를 생성하는 것으로 시작할 수 있습니다.

```powershell
# 1. Phoenix 설치 (설치되어 있지 않은 경우)
mix archive.install hex phx_new

# 2. 프로젝트 생성 (SQLite 사용 옵션)
# 깃허브 저장소 이름은 magic-split-mac, 프로젝트 내부 이름은 magic_split으로 합니다.
mix phx.new magic_split_mac --database sqlite3
```
