# [계획서] 종목별 자동매매 상세 설정 UI 구현

종목 클릭 시 나타날 '자동매매 상세 설정' 화면에 대한 설계안입니다.

## 1. 개요
사용자가 잔고 목록의 종목을 클릭하면, 해당 종목의 분할 매수/매도 전략을 세부적으로 수정할 수 있는 모달(Modal) 창을 제공합니다.

## 2. UI 구성 요소 (Mock-up 설계)

### 2.1. 상단 헤더 (Header)
- 종목명 및 코드 (예: 삼성전자 005930)
- 자동매매 활성화 스위치 (Toggle)
- 최대 관리 차수 설정 (Number Input)

### 2.2. 중앙 설정 영역 (2컬럼 레이아웃)
- **왼쪽 (매수 설정)**:
    - 각 차수별(1차~10차) 진입 방식 (수동/자동)
    - 하락 % 설정 및 투입 금액(원)
- **오른쪽 (매도 설정)**:
    - 각 차수별 목표 수익률(%) 설정
    - 시장가/지정가 선택

### 2.3. 하단 푸터 (Footer)
- **수익부스터**: 추가 옵션 설정
- **액션 버튼**: 취소, 설정 저장 (Indigo 컬러 강조)

## 3. 기술적 구현 (Phoenix LiveView)
- **이벤트**: `phx-click="select_stock"` 이벤트를 테이블 행(tr)에 추가
- **상태 관리**: `selected_stock` Assign을 추가하여 모달의 노출 여부 결정
- **컴포넌트**: `core_components.ex`에 있는 `<.modal>` 기능을 활용하여 macOS 스타일의 다크 모달 구현

---
> **전문가의 조언**: "트레이딩 설정은 오타 하나가 큰 손실로 이어질 수 있습니다. 입력창을 큼직하게 만들고, 저장 전 '정말 변경하시겠습니까?'라는 피드백을 주는 것이 중요합니다."
