# MagicSplit Mac UI/UX 설계 제안서

본 문서는 윈도우 버전의 매직스플릿 기능을 유지하면서, macOS 환경에 최적화된 모던하고 직관적인 UI 설계안을 제안합니다.

## 1. 디자인 철학
- **심플함 속의 강력함 (Simplicity but Powerful)**: 불필요한 테두리와 격자를 줄이고 여백을 활용하여 정보 가독성을 극대화합니다.
- **다크 모드 우선 (Dark Mode First)**: 장시간 트레이딩에도 눈이 편안한 깊은 네이비/그레이 톤의 다크 테마를 기본으로 합니다.
- **실시간 반응성 (Real-time Feedback)**: Phoenix LiveView를 활용하여 가격 변동 시 부드러운 애니메이션 효과를 부여합니다.

## 2. 레이아웃 구조 (3단 구성)

### A. 사이드바 (Navigation)
- **계좌 요약**: 현재 총 자산, 당일 손익률을 상시 표시
- **메뉴**: 실시간 잔고, 종목 검색, 매매 일지, 설정
- **토큰 상태**: 키움 API 연결 상태를 인디케이터로 표시

### B. 메인 대시보드 (Main Grid) - 핵심 화면
- **분할 매수 현황판**: 기존의 복잡한 그리드를 세련된 카드로 교체하거나, 가로 스크롤이 없는 컴팩트한 테이블로 구성합니다.
- **차수별 시각화**: 각 종목의 분할 매수 진행 상태(1차, 2차... n차)를 단순 숫자가 아닌 '프로그레스 바' 또는 '도트 인디케이터'로 표현하여 한눈에 진척도를 파악하게 합니다.

### C. 우측 패널 (Order & Info)
- **주문창 (Hoga)**: 선택한 종목의 호가창과 매수/매도 버튼을 배치합니다.
- **종목 상세**: 현재가, 전일대비, 거래량 등 핵심 지표만 요약 표시합니다.

---

## 3. 핵심 컴포넌트 상세 설계

### ① 실시간 잔고 테이블 (Stock Grid)
| 종목명 | 현재가 | 수익률 | 보유수량 | 매수평단 | 분할상태 (차수) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **삼성전자** | 72,500 | <span style="color: #ff4d4d">+2.5%</span> | 100 | 71,000 | ● ● ○ ○ ○ (2차) |
| **SK하이닉스** | 115,000 | <span style="color: #4d79ff">-1.2%</span> | 50 | 116,500 | ● ● ● ○ ○ (3차) |

- **애니메이션**: 가격 변동 시 배경색이 깜빡이는 효과 (Up: Red, Down: Blue)
- **인터랙션**: 종목 클릭 시 우측 주문창 즉시 연동

### ② 분할 매수 주문창 (Split Order)
- 윈도우 버전의 복잡한 설정을 **'프리셋(Preset)'**화 합니다.
- "보수적", "적극적", "직접 설정" 등의 버튼으로 초보자도 쉽게 분할 매수 전략을 선택할 수 있게 합니다.

---

## 4. 기술적 구현 포인트 (Phoenix + Tailwind)
- **Tailwind CSS**: `grid`, `flex`를 활용하여 창 크기 조절에 유연하게 대응
- **Heroicons**: macOS 스타일의 얇고 세련된 아이콘 사용
- **LiveView Stream**: 수백 개의 종목도 메모리 부하 없이 실시간 업데이트

## 5. 향후 확장성
- **차트 통합**: 가벼운 캔들 차트 라이브러리를 메인 대시보드 하단에 배치
- **알림 시스템**: 분할 매수 체결 시 macOS 시스템 알림(Notification) 연동
